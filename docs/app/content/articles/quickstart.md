Get up and running with Attractive.js and this script to your `<head>`.
```html
<script src="//unpkg.com/attractivejs" type="module" activate></script>
```


## First example

```html
<button on="toggleClass#active" on-target="panel">Toggle</button>

<div id="panel">Content</div>
```
